# 使用指南
程序分为左右两侧，左侧为日历区域，右侧为胶囊区域
### 日历区域
* 上下的横幅分别是时间指示器和天气
* 时间指示器指示当前显示月份和当前真实时间，单击真实时间回到今天
* 天气横幅的右侧为城市选择器，默认有位置识别，如果位置识别不生效，则可点击选择器，输入城市的英文名来选择对应城市
* 中间的月历部分，整体可以用滚轮滚动，数字格子可以单击、右键、双击
  * 滚动会切换显示的月份
  * 单击可以切换当前显示的日期
  * 双击可以让胶囊区域切换到双列模式，并滚动到对应的日期上
  * 右键可以在此日快捷创建一个带有这一天日程的胶囊
### 胶囊区域
* 默认为单列模式，双击日历格子切换为双列模式
* 双列模式下依靠“是否带有日程属性”而区分胶囊
* 双列模式中间的缝隙，使用鼠标悬停可以打开菜单
  * 单：切换到单列模式
  * \+：添加一个默认不带日程属性的胶囊
  * …：切换带有日程的胶囊的显示模式
    * 日程期间每天都显示
    * 只显示开始时间
    * 只显示结束时间
    * 只显示开始和结束时间
  * 字：切换默认提供的多种字体，未来会提供手动导入字体的功能
  * ☀️/🌙：切换深色、浅色模式
  * ⇅：导入和导出胶囊数据
  * 🗑：删除全部胶囊
### 其他
* 所有弹窗都在点击非弹窗区域后消失
* 天气提供今天、过去三天、未来六天的数据
* 月历中首行、尾行的高亮是固定日期的，中间行的高亮在切换月份之后会转移到对应月的首日或尾日
