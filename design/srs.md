## 1. 引言

### 1.1 编写目的

本文档旨在对 tasKapsule 时间胶囊桌面应用进行完整的需求描述，包括功能需求和非功能需求，作为后续设计、开发、测试和验收的依据。

### 1.2 项目范围

tasKapsule 是一款面向个人用户的本地桌面应用，基于 Electron + Vue 3 + Go 技术栈构建。用户可通过该应用记录日常笔记、灵感、待办事项等时间胶囊，并按时间线查看和管理。应用支持胶囊分类、日程绑定、日历视图、多语言、多时区、暗色/亮色主题等功能。

### 1.3 术语与定义

| 术语 | 说明 |
|---|---|
| 胶囊（Capsule） | 用户创建的一条记录，包含内容文本、分类、日程信息、附件等 |
| 日程（Schedule） | 胶囊绑定的时间安排，包含开始/结束时间、状态、死线 |
| 时间线（Timeline） | 按日期展开的日程胶囊列表视图 |
| 单列视图（A 模式） | 全部胶囊按创建时间倒序排列的单列布局 |
| 双列视图（B 模式） | 左列展示日程时间线，右列展示无日程胶囊的双列布局 |

## 2. 综合描述

### 2.1 产品概述

tasKapsule 是一款离线优先的桌面时间管理应用。用户通过创建"时间胶囊"记录日常事务，并通过日历、时间线、分类筛选等多种视图管理和回溯。应用采用 Go 后端 + SQLite 作为本地存储，Electron 提供桌面壳，Vue 3 作为前端渲染引擎。

### 2.2 产品功能

本应用涵盖以下核心功能域：

1. **胶囊管理** — 创建、查看、编辑、删除、分类、搜索时间胶囊
2. **日程管理** — 为胶囊绑定日程，按时间线查看
3. **日历视图** — 按月日历浏览，点击日期定位到对应日程
4. **视图切换** — 单列/双列两种布局模式
5. **个性化** — 主题切换（亮色/暗色）、语言切换（中/英/日）、时区切换
6. **媒体附件** — 上传音频和文件附件、设置闹钟提醒

### 2.3 用户特征

| 用户类型 | 特征描述 |
|---|---|
| 个人用户 | 使用桌面应用管理日常时间、笔记、灵感的个人用户，具备基本的计算机操作能力 |

### 2.4 约束条件

| 约束项 | 描述 |
|---|---|
| 技术栈 | Electron / Vue 3 / Go / SQLite |
| 运行环境 | Linux（主推）、macOS、Windows |
| 数据库 | SQLite 本地文件数据库，无远程服务器 |
| 浏览器内核 | Electron 内置 Chromium 108+ |
| 包管理器 | pnpm |
| CSS 标准 | CSS Viewport Units Level 3（dvb/dvi/svb/svi） |
| 端口占用 | 后端固定 9999 端口 |
| 后端语言 | Go 1.26.2，无框架 |

### 2.5 假设与依赖

- 用户拥有操作系统的基本操作能力
- 应用为单用户离线使用，不需要网络连接
- 用户本地文件系统可用，应用数据存储在 `~/.taskapsule/` 目录下
- Go 后端二进制文件与应用打包在一起，确保部署一致性
- 应用不支持多用户或用户登录体系

## 3. 功能需求

### 3.1 用户管理

#### 3.1.1 注册

| 项目 | 内容 |
|---|---|
| 描述 | 游客通过填写用户信息注册成为会员 |
| 输入 | 账号、密码、二次密码确认、手机号码、邮箱 |
| 处理 | 系统验证信息完整性，检查账号唯一性，创建用户记录 |
| 输出 | 注册成功跳转到成功页面；失败显示错误信息 |

#### 3.1.2 登录

| 项目 | 内容 |
|---|---|
| 描述 | 已注册用户通过账号密码登录系统 |
| 输入 | 账号、密码 |
| 处理 | 系统验证账号密码是否匹配 |
| 输出 | 登录成功跳转到主界面；失败提示"账号或密码错误" |

### 3.2 胶囊管理

#### 3.2.1 创建胶囊

| 项目 | 内容 |
|---|---|
| 描述 | 用户撰写并保存一条时间胶囊记录 |
| 输入 | 内容文本、分类、日程信息（可选）、附件（可选）、闹钟（可选） |
| 处理 | 1. 系统提供胶囊编辑界面<br>2. 用户输入内容和分类<br>3. 系统验证必填字段（内容文本不可为空）<br>4. 系统向后端发送 POST 请求<br>5. 后端写入 SQLite 数据库<br>6. 返回完整的胶囊对象 |
| 输出 | 新创建的胶囊数据，前端刷新列表 |
| 约束 | 默认分类为 `note`；`createdAt` 由数据库自动生成 |

#### 3.2.2 查看胶囊列表

| 项目 | 内容 |
|---|---|
| 描述 | 用户查看所有已创建的时间胶囊 |
| 输入 | 无 |
| 处理 | 1. 应用启动时自动向后端发送 GET 请求<br>2. 后端返回全部胶囊按 `created_at DESC` 排序<br>3. 前端渲染胶囊卡片列表 |
| 输出 | 胶囊卡片列表，每个卡片显示内容摘要、分类颜色 |
| 异常 | 后端不可用时显示错误提示 |

#### 3.2.3 查看胶囊详情

| 项目 | 内容 |
|---|---|
| 描述 | 用户点击胶囊卡片，展开查看完整内容和日程信息 |
| 输入 | 用户点击某个胶囊卡片 |
| 处理 | 1. 胶囊卡片从摘要态展开为详情态<br>2. 显示完整内容文本<br>3. 如有日程，显示日程详情 |
| 输出 | 展开状态的胶囊卡片 |
| 约束 | 再次点击同一胶囊可收起 |

#### 3.2.4 编辑胶囊

| 项目 | 内容 |
|---|---|
| 描述 | 用户修改已有胶囊的内容 |
| 输入 | 修改后的胶囊字段 |
| 处理 | 1. 用户进入编辑模式<br>2. 系统加载当前胶囊数据<br>3. 用户修改后点击保存<br>4. 后端执行全字段替换 PUT 操作 |
| 输出 | 更新后的胶囊数据 |
| 异常 | 胶囊已被删除时提示 404 |

#### 3.2.5 删除胶囊

| 项目 | 内容 |
|---|---|
| 描述 | 用户永久删除一条胶囊记录 |
| 输入 | 用户点击删除并确认 |
| 处理 | 1. 系统弹出确认对话框<br>2. 用户确认后发送 DELETE 请求<br>3. 后端执行 SQLite DELETE 操作 |
| 输出 | 被删除胶囊从列表中消失 |
| 异常 | 胶囊不存在时提示 404 |

#### 3.2.6 分类胶囊

| 项目 | 内容 |
|---|---|
| 描述 | 用户为胶囊选择分类标签 |
| 输入 | 分类枚举之一 |
| 处理 | 1. 系统展示五种分类选项<br>2. 用户选择一项<br>3. 胶囊卡片颜色实时更新为对应的分类色 |
| 输出 | 分类文本和颜色 |
| 枚举 | note（蓝 #6890ED）、urgent（红 #F86666）、favourite（橙 #FFA74E）、sms（绿 #60D14D）、inspiration（紫 #A564DE） |

#### 3.2.7 搜索胶囊

| 项目 | 内容 |
|---|---|
| 描述 | 用户按关键词搜索胶囊内容 |
| 输入 | 搜索关键词字符串 |
| 处理 | 1. 用户输入关键词<br>2. 系统实时过滤胶囊列表<br>3. 匹配 `contentText` 包含关键词的记录 |
| 输出 | 过滤后的胶囊列表 |
| 异常 | 无匹配结果显示"未找到"提示 |

### 3.3 日程管理

#### 3.3.1 管理日程

| 项目 | 内容 |
|---|---|
| 描述 | 用户为胶囊绑定或修改日程信息 |
| 输入 | 日程开关、开始时间、结束时间、死线、日程状态 |
| 处理 | 1. 用户开启"有日程"开关<br>2. 系统显示日程编辑区域<br>3. 用户设置时间信息<br>4. 系统验证时间合法性（开始 ≤ 结束） |
| 输出 | 胶囊的 `isWithSchedule` 标记和相关时间字段 |
| 约束 | 开始时间不能晚于结束时间 |

#### 3.3.2 查看日程时间线

| 项目 | 内容 |
|---|---|
| 描述 | 在双列视图下查看按日期展开的日程时间线 |
| 输入 | 用户切换至双列视图 |
| 处理 | 1. 系统将所有 `isWithSchedule=1` 的胶囊按日期范围展开<br>2. 根据 `displayMode` 设置决定显示哪些日期条目<br>3. 按日期排序渲染 |
| 输出 | 按日期排序的日程胶囊条目列表 |
| 模式 | all（全部日期）、first-last（首尾日期）、first（首日）、last（末日） |

### 3.4 日历与视图

#### 3.4.1 查看日历

| 项目 | 内容 |
|---|---|
| 描述 | 用户按月查看日期布局 |
| 输入 | 当前月信息 |
| 处理 | 1. 系统根据当前时区计算当月天数、月初曜日<br>2. 渲染上月尾部、当月全部、下月头部的 7×N 网格 |
| 输出 | 日历网格，当天高亮 |

#### 3.4.2 按日期定位胶囊

| 项目 | 内容 |
|---|---|
| 描述 | 用户点击日历日期，胶囊时间线滚动到对应位置 |
| 输入 | 用户点击某一天 |
| 处理 | 1. 点击日期高亮为蓝色选中态<br>2. 非本月日期切换月份<br>3. 时间线滚动到该日期 |
| 输出 | 日期选中态更新，时间线滚动 |

#### 3.4.3 切换视图模式

| 项目 | 内容 |
|---|---|
| 描述 | 用户在单列和双列模式间切换 |
| 输入 | 用户点击切换按钮 |
| 处理 | 1. A 模式：全部胶囊按创建时间排列<br>2. B 模式：左侧日程时间线 + 右侧无日程胶囊 |
| 输出 | 胶囊面板重新排列 |

### 4.4 可移植性

| 编号 | 需求描述 | 指标 |

### 4.5 安全性

| 编号 | 需求描述 | 指标 |
|---|---|---|
| NFR-20 | 离线单用户 | 应用为完全离线桌面应用，不依赖网络连接，无用户认证 |

### 4.6 可维护性

| 编号 | 需求描述 | 指标 |

| NFR-27 | 状态管理 | 使用 Pinia 分离全局状态（主题、语言、时区、胶囊数据） |

| NFR-29 | 包管理器 | 统一使用 pnpm 管理依赖，构建脚本集中在 root package.json |
| NFR-30 | 代码规范 | Vue 3 Composition API + `<script setup>`、Go 标准格式（`gofmt`） |

## 5. 数据模型

### 5.1 数据库表结构

**表名**：`capsules`

| 列名 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| created_at | TEXT | NOT NULL DEFAULT datetime('now','localtime') | 创建时间 |
| content_text | TEXT | NOT NULL DEFAULT '' | 胶囊内容文本 |
| audio_path | TEXT | nullable | 音频文件路径 |
| attachment_paths | TEXT | nullable | 附件路径列表（JSON 数组字符串） |
| classification | TEXT | NOT NULL DEFAULT 'note' | 分类枚举 |
| is_with_schedule | INTEGER | NOT NULL DEFAULT 0 | 是否有日程（0/1） |
| schedule_icon | TEXT | nullable | 日程图标 |
| schedule_content_text | TEXT | nullable | 日程内容 |
