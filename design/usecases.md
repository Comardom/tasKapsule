# tasKapsule 项目需求模型 — 用例描述

## 参与者

| 参与者 | 描述 |
|---|---|
| 用户 | 使用时间胶囊桌面应用的普通用户 |
| 系统 | 后台自动执行的操作（闹钟提醒、定时保存） |

## 3. 创建胶囊

| 字段 | 内容 |
|---|---|
| 用例编号 | XXX_003 |
| 用例名 | 创建胶囊 |
| 用例描述 | 用户撰写一条新的时间胶囊记录，包含内容文本、分类、日程信息等 |
| 参与者 | 用户 |
| 前置条件 | 用户已登录 |
| 基本路径 | 1. 用户点击"新建胶囊"按钮<br>2. 系统显示胶囊编辑界面<br>3. 用户输入胶囊内容文本<br>4. 用户选择分类（笔记/紧急/收藏/短信/灵感）<br>5. 用户可选添加日程（开始时间、结束时间、死线、状态）<br>6. 用户可选上传附件/设置闹钟<br>7. 用户点击"保存"按钮<br>8. 系统验证必填字段<br>9. 系统保存胶囊并返回完整胶囊数据<br>10. 系统刷新胶囊列表 |
| 其他路径 | 8a. 必填字段为空 → 系统提示"内容不可为空"，停留在编辑界面<br>4a. 用户未选择分类 → 系统默认为"笔记" |
| 异常事件 | 数据库写入失败 → 系统提示"保存失败，请重试" |
| 后置条件 | 系统胶囊列表新增一条记录 |

## 6. 编辑胶囊

| 字段 | 内容 |
|---|---|
| 用例编号 | XXX_006 |
| 用例名 | 编辑胶囊 |
| 用例描述 | 用户修改已有胶囊的内容、分类、日程信息 |
| 参与者 | 用户 |
| 前置条件 | 用户已登录，至少有一条胶囊记录 |
| 基本路径 | 1. 用户在胶囊详情界面点击"编辑"按钮<br>2. 系统加载胶囊当前数据到编辑界面<br>3. 用户修改内容<br>4. 用户点击"保存"<br>5. 系统向后端发送 PUT 请求更新全部字段<br>6. 系统返回更新后的胶囊数据<br>7. 系统刷新列表和详情显示 |
| 其他路径 | 5a. 后端返回 404 → 系统提示"该胶囊已被删除" |
| 异常事件 | 数据库更新失败 → 系统提示"更新失败，请重试" |
| 后置条件 | 系统胶囊数据更新 |

## 7. 删除胶囊

| 字段 | 内容 |
|---|---|
| 用例编号 | XXX_007 |
| 用例名 | 删除胶囊 |
| 用例描述 | 用户永久删除一条时间胶囊记录 |
| 参与者 | 用户 |
| 前置条件 | 用户已登录，至少有一条胶囊记录 |
| 基本路径 | 1. 用户在胶囊详情界面点击"删除"按钮<br>2. 系统弹出确认对话框"确定删除此胶囊？"<br>3. 用户点击"确认"<br>4. 系统向后端发送 DELETE 请求<br>5. 后端返回 204 No Content<br>6. 系统刷新胶囊列表，被删除的胶囊消失 |
| 其他路径 | 3a. 用户点击"取消" → 关闭对话框，不做任何操作<br>4a. 后端返回 404 → 系统提示"该胶囊已被删除" |
| 异常事件 | 无 |
| 后置条件 | 该系统胶囊永久移除 |
