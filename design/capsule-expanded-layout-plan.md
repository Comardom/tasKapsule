# 胶囊展开态内容布局方案

## 1. 目标

调整胶囊展开后的信息展示方式，避免将创建时间、分类、日程、附件路径和闹钟 JSON 直接逐行平铺。

展开态应明确分为正文阅读区和操作信息区：

```text
胶囊正文
────────────────────
[ 笔记 ] [ 紧急 ] [ 收藏 ] [ 短信 ] [ 灵感 ]
[ 创建时间 ] [ 日程时间 ] [ 状态 ] [ 截止时间 ] [ 闹钟 ] [ 附件 ]
[ 编辑 ] [ 删除 ]
```

## 2. 分隔线

在完整正文和下方操作信息区之间增加一条 `hr`：

- 仅在胶囊展开时显示。
- 用于分隔正文阅读区和元数据、操作区。
- 边线颜色应由主题变量或半透明色控制，保持当前玻璃风格。

## 3. 第一排：分类按钮

固定显示五个小型分类按钮：

```text
[ 笔记 ] [ 紧急 ] [ 收藏 ] [ 短信 ] [ 灵感 ]
```

分类对应现有枚举：

| 按钮 | 分类值 |
|---|---|
| 笔记 | `note` |
| 紧急 | `urgent` |
| 收藏 | `favourite` |
| 短信 | `sms` |
| 灵感 | `inspiration` |

行为：

- 当前分类必须有明确的高亮状态。
- 点击分类按钮后，直接更新该胶囊分类。
- 卡片颜色随分类立即更新。
- 不必先打开完整编辑弹窗。

分类按钮应保持紧凑，避免显著增加胶囊展开高度。

## 4. 第二排：信息与功能按钮

第二排只显示该胶囊实际拥有的信息或可用功能。

| 按钮 | 显示条件 |
|---|---|
| 创建时间 | 始终显示 |
| 日程时间 | `isWithSchedule === 1` 或存在日程时间字段 |
| 日程状态 | 存在 `scheduleStatus` |
| 截止时间 | 存在 `scheduleDeadline` |
| 闹钟 | 存在 `alarmClocks` |
| 附件 | 存在 `attachmentPaths` |
| 音频 | 存在 `audioPath` |

原则：

- 不直接将长路径、完整 JSON 或全部元数据堆在正文下方。
- 信息按钮应提供可识别的简短标签或图标。
- 编辑和删除也应保留，可放在第二排右侧或独立操作区。
- 删除保持危险样式，并继续使用确认弹窗。
- 编辑继续打开完整编辑表单，适合修改正文和复杂日程字段。

## 5. 信息按钮的交互待定

信息按钮点击后的具体行为尚未确定，候选方式：

1. 在当前胶囊内部展开对应详情。
2. 鼠标悬停显示简短提示，点击无额外动作。
3. 点击后打开独立小弹窗或浮层。

当前建议优先考虑方式 1：信息保留在当前胶囊的上下文中，不会像弹窗一样打断阅读和编辑流程。

## 6. 保留与调整

保留：

- 当前正文的折叠和展开动画。
- 当前完整编辑弹窗。
- 当前删除确认流程。
- 现有五种分类和卡片分类色。

调整：

- 展开态不再默认逐行显示所有字段。
- 分类由纯展示文本变为可直接点击的操作按钮。
- 元数据和扩展功能按字段是否存在决定是否显示。
