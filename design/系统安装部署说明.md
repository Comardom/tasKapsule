# Electron版本的从源码部署
去github[tasKapsule-electron](https://github.com/Comardom/tasKapsule-electron.git)拉取源码<br />
## Go
- 自行在官网上下载
## Node.js
- 使用 **nvm** 管理 Node 版本
- 安装方法请自行查阅
- 安装并使用 **lts/krypton** 版本（v24.14.0）
## Node 包管理器
我们统一使用 **npm + pnpm**：
- npm 一般随 Node.js 一起安装，如果没有则运行：
  nvm install-latest-npm
- 安装 pnpm：
  npm install -g pnpm
  pnpm setup
## SQLite
- 非 Windows：用包管理器安装
- Windows：在 PowerShell 中运行：
```shell
choco install sqlite
```
## 测试
根目录：
```shell
cd backend/
go run .
cd ../

cd frontend/
pnpm install
pnpm dev
```
## 打包
根目录：
```shell
pnpm build:backend     # 编译 Go 后端
pnpm dist:linux        # Linux: AppImage + deb + rpm
pnpm dist:win          # Windows: NSIS 安装包
```
